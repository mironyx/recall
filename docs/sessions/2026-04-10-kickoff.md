## Decisions and rationale captured this session

- **No SSE shim, no stdio fallback** — design principle 4 enforced mechanically by ADR-0006.
- **Bearer tokens, restart-to-rotate** — small-team operational cost accepted; OIDC is a v2 ADR.
- **Two embeddings providers behind one interface** — local-dev ergonomics + production flexibility worth the test-matrix cost.
- **`projects` table, no config-file fallback** — multi-machine consistency is exactly what shared infrastructure needs.
- **Additive ranking boost** — preserves "strong global hit can outrank weak project hit" mechanically; constant is an env-var knob, not a code change.
- **structlog + OTEL auto only, exporter off by default** — locks the v1 ceiling so observability cannot accrete spans/metrics by accident.
- **Real Postgres on every PR** — promoted from CLAUDE.md "never do" to ADR-0012 so the rule survives CLAUDE.md edits.
- **In-app DDL runner, no Alembic** — schema is small, testcontainers fixture wants one Python function, ceremony tax was the deciding factor.
