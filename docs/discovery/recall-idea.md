This is an idea for long term memory for AI coding agents.
when the team of agents work on a project, they should be able to access the project's history and context.
The setup is - a team of humans work on a project, and they use AI coding agents to help them.
The AI coding agents should be able to access the project's history and context.
Currently Claude Code has a memory feature, but it's limited to a single project.
IT should be self-hosted by the team and we are planning to use Langmem/LAngGraph with pg-vector.
